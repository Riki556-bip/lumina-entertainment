LUMINA ENTERTAINMENT — VERSION 2
=================================

Fichiers :
- index.html : accueil
- lunelys.html : projet LUNELYS
- auditions.html : page auditions
- staff.html : page staff
- style.css : design responsive, couleurs, cartes et décorations
- script.js : menu mobile, année automatique et liens WhatsApp

CONFIGURER WHATSAPP
1. Ouvre script.js dans un éditeur de texte.
2. Remplace TONNUMERO par le numéro WhatsApp Business/de l'agence au format international, chiffres uniquement.
   Exemple fictif pour la France : 33612345678
3. Enregistre le fichier.
Ne publie pas un numéro personnel sans autorisation.

PUBLIER SUR GITHUB PAGES
1. Crée un dépôt GitHub Public.
2. Envoie les 6 fichiers listés ci-dessus directement à la racine du dépôt (pas dans un sous-dossier).
3. Dans le dépôt, ouvre Settings > Pages.
4. Dans Build and deployment, sélectionne Deploy from a branch.
5. Choisis la branche main et le dossier /(root), puis Save.
6. Attends le déploiement. L'adresse du site sera affichée dans Settings > Pages.

NOTES
- Le site est statique : il ne collecte pas de formulaires et n'a pas de base de données.
- Les candidatures et contacts passent par les liens WhatsApp configurés.
- Les noms du staff sont des exemples à remplacer.
- Les polices Google Fonts nécessitent une connexion internet ; des polices de secours sont prévues.
